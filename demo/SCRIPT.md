# CleanAirSchool demo video

Narrated 1080p walkthrough of the post-revamp daylight mineral-teal UI,
covering the above-the-fold EPA 2024 AQI band, the one-click wildfire
classroom intervention demo, scenario presets, the filtration calculator,
the 120-minute decay chart, bilingual notices, cost comparison, the in-page
EPA benchmark, and the fleet lab with its self-test and digest proofs.
Everything below is produced locally and repeatably; no API keys, no
network calls, no signed-in browser.

## Files

| File | Role |
| --- | --- |
| `demo/narration.txt` | Voiceover source. One sentence per line, blank line between paragraphs. |
| `demo/steps.json` | The drive plan. `at` steps pin actions to narration marks (`"mark": "2.1"` = paragraph 2 sentence 1). Adds `scroll`, `select`, `num`, `sweep` and `cursor` steps on top of the base vocabulary. |
| `demo/timing.json` | Measured per-sentence start/duration from the synthesized audio. Regenerated by `synth`. |
| `demo/narration.wav` | Assembled voiceover (macOS `say`, voice Samantha, 170 wpm, 24 kHz mono). |
| `demo/captions.ass` | Lower-third captions burned into the video (white on a translucent dark box). |
| `demo/cleanair-school-demo.srt` | Companion captions file for upload. |
| `demo/test-proof.txt` | Real outputs of `node --test tests/`, `node scripts/run-eval.mjs --check` and the honesty harness, captured during `capture` and shown on screen near the end. |
| `demo/cleanair-school-demo.mp4` | The finished video. |
| `scripts/record-demo.mjs` | The whole pipeline: `synth`, `capture`, `check`, `all`. |
| `scripts/serve.mjs` | Zero-dependency static server used by `capture`. |

## Reproduce

```bash
npm run demo:synth     # narration.txt -> narration.wav + timing.json + captions
npm run demo:capture   # proof + serve + headless Chrome drive -> demo/cleanair-school-demo.mp4
npm run demo:check     # ffprobe report
```

`capture` first writes `demo/test-proof.txt` from live command output, then
starts `scripts/serve.mjs` on an ephemeral port and drives the app in a
throwaway headless Chrome (empty profile, ephemeral CDP port, real mouse
and key events, a visible drawn cursor). The screencast resamples to a
constant 30 fps and muxes the narration plus burned captions in one ffmpeg
pass. All temp files live in `CLEANAIR_DEMO_TMP` (or a fresh `mkdtemp` dir)
and are deleted on exit. Downloads are pinned to the temp dir and the drive
aborts if the page ever leaves the demo origin.

## Honesty note

The video is an honest capture of this repo running in a plain browser on a
local static server. Every figure on screen is a labeled modeled
engineering projection; no school pilot, purchase or measured outcome is
claimed. The verification panel quotes `demo/test-proof.txt`, which is
regenerated from real command output on every `capture` run.
